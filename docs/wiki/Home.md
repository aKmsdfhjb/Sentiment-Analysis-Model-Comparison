# Sentiment Analysis Model Comparison — Project Wiki

Research project comparing classical text classifiers and a GRU sequence model. The tracked repository snapshot contains an empty dataset file and lacks required preprocessing artifacts, so live inference is intentionally not enabled.

## Quick start

Inspect `notebooks/Code.ipynb` and the model inventory in the README. Restore a licensed dataset and regenerate preprocessing artifacts before attempting reproducible training or inference.
